# 实验流程编写与安全复核工具

面向研究人员和实验室安全复核人员的纯前端工作台。实验步骤、复核批注和冻结版本均保存在浏览器本机，可离线编辑。

## 功能

- 按步骤维护名称、目的、材料、设备、用量、预计时间、危险项、控制措施、安全说明、预期结果和依赖关系。
- 添加、复制、删除、上下移动实验步骤，通过复选框建立前置依赖。
- 修改步骤后自动计算全部下游步骤，提醒受影响的后续步骤和已确认内容。
- 自动识别存在危险项但缺少控制措施或安全说明的步骤，并阻止确认与冻结。
- 提交复核后，复核人可逐条添加批注、标记解决、确认或退回。
- 所有步骤确认且安全信息完整后冻结版本；冻结后只能从该版本创建修订稿。
- 保存多个完整版本快照，比较步骤新增、删除及材料、用量、危险项、依赖等字段变化。
- 版本归档：先估算可释放空间，把连续完整快照按字段差异收成增量；批准、电子签名、事故关联和修订来源版本列为保留项，不参与回收。
- 本地容量不足时拒绝写入并列出可回收候选，用户确认后才执行压缩；压缩前在内存重建校验并备份 localStorage，失败自动恢复归档前数据。
- 归档后的版本统一经物化入口读取，版本比较、修订分支和撤销重做看到的是同一份结果；旧数据缺少归档信息时自动兼容迁移。
- 完整撤销重做、本地自动保存和 `Ctrl/Cmd+S` 手动保存。

## 技术栈

- React 19 + TypeScript
- Vite
- Blueprint UI (`@blueprintjs/core`、`@blueprintjs/icons`)
- 浏览器 localStorage
- Nginx 静态部署

## 本地开发

```bash
npm install
npm run dev
```

开发服务器监听 `5173`，宿主端口仅由部署映射，源码未写入 `10027`。

## 归档逻辑测试

```bash
npm run test:archive
```

用 esbuild 将 `src/archive.ts`、`src/storage.ts` 打包到临时 bundle 后由 Node 执行，
覆盖增量编码与无损重建、保留项保护、可释放空间、落盘失败回滚、压缩失败恢复和旧数据迁移。

## 生产构建

```bash
npm install
npm run build
```

构建产物位于 `dist`。

## Docker

```bash
docker build -t sologsb-1027 .
docker run --rm -p 10027:80 sologsb-1027
```

容器内 Nginx 监听 `80`，访问 `http://localhost:10027`。实验数据仅保存在当前浏览器。
